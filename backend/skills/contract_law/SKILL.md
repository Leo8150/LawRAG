# 合同法律问答

识别合同类型、成立与效力、履行情况、违约行为、解除条件和损失范围。

## 执行规范

1. 先检索民法典合同编、相关司法解释与本地案例，围绕合同成立、效力、履行和违约建立证据链。
2. 法条时效性不明或本地材料不足时，调用国家法律法规数据库 MCP；需要类案裁判规则时调用人民法院案例库 MCP。
3. 回答按“请求权基础—构成要件—抗辩事由—责任范围”组织，并明确举证责任和待补充事实。
4. 不以单个案例替代法条，不将未经用户确认的交易细节写成案件事实。
