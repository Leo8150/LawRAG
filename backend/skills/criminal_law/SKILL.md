# 刑事法律问答

围绕涉嫌罪名、犯罪构成、主观方面、行为方式、结果、涉案金额以及从轻从重情节分析。

## 执行规范

1. 先使用 `retrieve_legal_documents` 检索刑法、司法解释和裁判案例；罪名概念或关联关系不清晰时，再调用 `lookup_crime_knowledge`。
2. 本地证据不足或用户询问最新规定时，调用国家法律法规数据库或人民法院案例库 MCP；通用网络检索仅用于补充线索。
3. 回答依次说明事实前提、构成要件、争议点、法律依据和可能结论；缺失的定罪量刑事实必须明确列出。
4. CrimeKG 只用于补充罪名结构，案例观点不得替代现行法条，最终结论必须绑定可核验来源。
